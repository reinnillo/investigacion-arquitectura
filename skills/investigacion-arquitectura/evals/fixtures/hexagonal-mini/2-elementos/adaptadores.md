# Adaptadores

## Qué es un adaptador
<!-- @HEX-ELE-3 -->

- Un adaptador convierte entre una tecnología concreta y la API de un puerto **[P]**.
- Cambiar de tecnología es cambiar de adaptador; la aplicación no cambia **[P]**.

## Adaptadores de prueba
<!-- @HEX-ELE-3A -->

- Un arnés de tests automáticos sustituye a la interfaz de usuario en el lado primario **[P]**.
- Una base de datos simulada en memoria sustituye a la real en el lado secundario **[P]**.
